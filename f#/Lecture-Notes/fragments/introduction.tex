This lecture develops the theory of formal languages through scanners, parsers, interpreters and compilers.
The host language of this edition is F\#, with static type inference, algebraic data types and the .NET standard library.
FsLex generates scanners from regular-expression rules, while FsYacc generates LALR parsers with typed semantic actions.
The mathematical definitions, proofs and target languages remain those of the original course.
The implementation material is drawn directly from the executable F\# notebooks.
