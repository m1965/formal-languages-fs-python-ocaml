\paragraph{F\# code-generation conventions}
The algebra below specifies the same JVM stack effects as the original lecture.
In this edition the implementation functions are \texttt{compileExpr}, \texttt{compileStatement},
\texttt{compileFunction} and \texttt{compileProgram}. The original mathematical spelling
\texttt{compile\_expr} denotes the corresponding expression transformation.
Their complete implementations appear after the individual specifications, so the formulas can be studied
without repeatedly printing a partially defined function.
The syntax tree is a discriminated union and the symbol table is an immutable map.
