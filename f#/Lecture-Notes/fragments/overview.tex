\section{Overview}
\begin{enumerate}
\item Define regular expressions and their languages; use the .NET regular-expression library for practical searches.
\item Generate scanners with FsLex and construct finite automata. Translate between expressions, NFAs and DFAs and minimize DFAs.
\item Study the closure properties and limits of regular languages.
\item Define context-free grammars, derivations, ambiguity and EBNF; implement recursive descent with mutually recursive F\# functions.
\item Use FsYacc for a calculator, symbolic differentiation and a small interpreter.
\item Derive Earley, shift-reduce, SLR, canonical LR and LALR parsing algorithms.
\item Investigate generated conflicts and precedence using real FsYacc specifications.
\item Study JVM/Jasmin assembly and compile Integer-C with an F\# frontend and code generator.
\end{enumerate}
F\# is the implementation language; Integer-C and Jasmin are the source and target languages of the compiler.
Historical Java examples illustrate the JVM and are retained for that purpose.
