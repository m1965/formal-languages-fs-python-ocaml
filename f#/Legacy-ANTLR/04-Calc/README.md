# Visitor calculator with FsLexYacc

This is the F# counterpart of `ANTLR4-Python/04-Calc/Parser.ipynb`. `Expr.g4` is preserved for comparison; the executable grammar and scanner are the adjacent `.fsy` and `.fsl` files, generated by `Calculator/Calculator.fsproj` with FsLexYacc 11.3.0.

The visible notebook visitor separates parsing from evaluation, uses typed union cases, preserves undefined identifiers as zero, uses arbitrary-precision integers, and explicitly implements Python's floor division for negative operands. The original example prints 25 twice. The parser builds without unresolved conflicts.
